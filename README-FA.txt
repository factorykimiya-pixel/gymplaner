FitnessCut - نسخه وب آماده انتشار با Vercel Drop

این پوشه شامل index.html، manifest.webmanifest، sw.js و icons است. تصاویر داخل index.html جاسازی شده‌اند. ۵ بخش تغذیه، مکمل، PUSH، PULL و LEGS از فایل قبلی حفظ شده‌اند و روی موبایل و دسکتاپ ریسپانسیو هستند. در قسمت چاپ هر پنج بخش روی برگه‌های A4 جداگانه چاپ می‌شوند.

بدون GitHub و مک:
۱) فایل FitnessCut_Vercel_Ready.zip را دریافت کن.
۲) https://vercel.com/drop را باز کن و وارد حساب Vercel شو.
۳) ZIP را در Vercel Drop بارگذاری کن. نام پروژه را fitnesscut بگذار، سپس Deploy کن.
۴) آدرس HTTPS تولیدشده را در Safari آیفون باز کن؛ در صورت تمایل Share > Add to Home Screen را انتخاب کن.

نکته: اولین بازشدن سایت اینترنت می‌خواهد. پس از نخستین بازدید و نصب Service Worker، ممکن است محتوای سایت در حالت آفلاین هم نمایش داده شود؛ حافظه کش مرورگر ممکن است پاک شود. این سایت صرفاً نمایشگر راهنمای تغذیه و تمرین است و فعلاً پایگاه داده یا همگام‌سازی بین دستگاه‌ها ندارد.

در Vercel Drop هر آپلود یک پروژه تازه می‌سازد. برای به‌روزرسانی همان URL، از Vercel CLI با vercel deploy --prod در رایانه یا اتصال گیت استفاده کن.
